# Everclean Carwash Simulator

A browser shift simulator inspired by my real part-time job at a car wash. Run the line, keep customers happy, and survive the rush.

## Run
Open `carwash.html` in a browser, or serve it:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000/carwash.html.

## Stack
Single-file HTML, CSS and JavaScript. Background music and art assets are included. Images were generated with Higgsfield.
